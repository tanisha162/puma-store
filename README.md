## 📌 Project Overview
A visually striking product showcase and e-commerce hero concept for athletic footwear. Features dynamic shoe colorway selectors, perspective-tilted 3D card interactions, and clean responsive layout architecture.

---

## 🚀 How to Run
Simply clone and open `index.html` in any modern web browser:
```bash
git clone https://github.com/tanisha162/puma-store.git
cd puma-store
# Open index.html in your browser
```
